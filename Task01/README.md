# Лабораторная работа № 1

Исходные данные скопированы из каталога `dataset`. CSV-файлы содержат строку заголовков, значения разделены запятыми.

| Файл | Содержимое |
| --- | --- |
| `movies.csv` | `movieId` — идентификатор фильма, `title` — название, `genres` — жанры через вертикальную черту. |
| `ratings.csv` | `userId` — идентификатор пользователя, `movieId` — идентификатор фильма, `rating` — оценка, `timestamp` — время в секундах Unix. |
| `tags.csv` | `userId` — идентификатор пользователя, `movieId` — идентификатор фильма, `tag` — текст метки, `timestamp` — время в секундах Unix. |
| `users.txt` | Идентификатор, имя, электронная почта, пол, дата рождения (`ГГГГ-ММ-ДД`) и профессия. Поля разделены вертикальной чертой. |
| `genres.txt` | Список жанров, по одному на строку. |
| `occupation.txt` | Список профессий, по одной на строку. |

В `ratings_count.txt` каждая строка содержит идентификатор пользователя и количество его оценок. Сначала записан минимальный идентификатор, затем максимальный.
