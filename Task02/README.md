# Лабораторная работа № 2

Скрипт загружает исходные данные о фильмах, пользователях, оценках и тегах в базу SQLite.

## Запуск

Нужны Bash, Python 3 и консольный клиент SQLite. Команды `python3` и `sqlite3` должны быть доступны в `PATH`. В Windows можно использовать Git Bash.

```bash
cd Task02
./db_init.bat
```

Скрипт создаёт `db_init.sql` и выполняет его в базе `movies_rating.db`. Повторный запуск пересоздаёт четыре таблицы и загружает исходные данные заново. SQL-скрипт и база создаются при запуске.

## Преобразование исходных данных

| Таблица | Источник | Преобразование |
| --- | --- | --- |
| `movies` | `movies.csv` | Год в скобках в конце названия выделяется в поле `year`. Если года там нет, записывается `NULL`. Жанры сохраняются одной строкой. |
| `users` | `users.txt` | Поля разделены вертикальной чертой. Дата регистрации сохраняется в формате `ГГГГ-ММ-ДД`. |
| `ratings` | `ratings.csv` | Оценка хранится как `REAL`, время — в секундах Unix как `INTEGER`. |
| `tags` | `tags.csv` | Текст метки хранится как `TEXT`, время — в секундах Unix как `INTEGER`. |

Идентификаторы фильмов и пользователей сохраняются из исходных файлов. SQLite присваивает идентификаторы строкам оценок и тегов. Списки `genres.txt` и `occupation.txt` скопированы вместе с остальными исходными файлами.

Для проверки количества строк можно выполнить:

```bash
sqlite3 movies_rating.db "SELECT 'movies', COUNT(*) FROM movies UNION ALL SELECT 'users', COUNT(*) FROM users UNION ALL SELECT 'ratings', COUNT(*) FROM ratings UNION ALL SELECT 'tags', COUNT(*) FROM tags;"
```
